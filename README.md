Vice City Cover Studio — turn any photo and caption into multi-panel GTA 6-style cover art: a Vice City sunset or neon grade, bold poster lettering, drag-to-crop panels, and one-click PNG export in post sizes (1080x1080, 1080x1350, 1920x1080). Runs entirely offline in a desktop browser; photos never leave the machine. Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
